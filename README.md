# ReformaOferta

Sitio web estático de afiliados, preparado para publicar gratis con GitHub Pages.

## Publicación en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `reformaoferta`.
2. Sube `index.html`, `styles.css` y `script.js`.
3. En GitHub entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
5. Guarda y espera a que GitHub publique la web.

## Antes de publicarla

Los productos incluidos son ejemplos. Debes sustituir sus enlaces por tus enlaces de afiliado reales.

Edita `script.js` y cambia cada propiedad `url` por la URL proporcionada por el programa de afiliación.

También conviene añadir páginas de:
- Aviso legal
- Política de privacidad
- Política de cookies, si corresponde
- Condiciones de uso
- Información sobre enlaces de afiliados

No copies fotografías, descripciones o precios de tiendas sin comprobar que el programa de afiliación o la licencia correspondiente permite utilizarlos.
